# SpeachText1.0 instructional walkthrough

## Production brief

| Field | Decision |
|---|---|
| Purpose | Help a new macOS user install SpeachText1.0, grant required permissions, and understand its principal privacy and productivity tools. |
| Audience | Individual Mac users who want private, local-first dictation. |
| Duration | 90 seconds. |
| Format | 16:9 landscape, 1920×1080 presentation style. |
| Language | English. |
| Narration | Calm, clear adult English voice-over at a measured pace. |
| Music | None. Soft interface clicks and subtle confirmation tones only. |
| Visual method | Clean macOS-inspired screen-demo animation; no personal data, brand impersonation, or real credentials shown. |

## Global visual definition

| Dimension | Specification |
|---|---|
| Sub-genre | Premium product walkthrough with a friendly, local-first technology feel. |
| Rendering and line | Crisp desktop UI simulation, subtle depth, flat vector-like panels, restrained motion graphics. |
| Color and lighting | Warm off-white desktop, deep slate panels, SpeachText indigo-to-cyan accents, soft ambient shadows. |
| Detail density | Moderate: clearly legible large controls, uncluttered menus, no dense incidental text. |

## Recurring visual elements

| Identifier | Appearance and use |
|---|---|
| SpeachText app | A compact rounded macOS utility window with an indigo-to-cyan waveform mark, slate header, pale canvas, and clearly separated controls. |
| Desktop setting | A clean generic Mac desktop with no personal files, messages, contacts, browser tabs, or accounts. |
| Privacy Lock badge | Small shield icon with a cyan edge, shown only for protected-context explanations. |
| Recovery Vault badge | Small locked archive icon with a returning-arrow accent. |

## Continuity and audio notes

All clips use independent scene cuts except that clips 4 and 5 share the same generic note-window visual language. There is no music bed. Each clip has a single narration span sized to fit its duration, with soft interface click sounds only where a permission, action preview, setting tile, or vault action visibly changes state.
